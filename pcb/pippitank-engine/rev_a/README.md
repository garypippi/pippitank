## 電流測定 (ESC)

シャント抵抗は1W7mΩ ±5%を調達
並列数は4、 上限30Aとして

- 各抵抗の電流: 7.5A
- 各抵抗の電力: 0.394W
- 電圧降下@30A: 52.5mV
- 必要利得    : 20.95
- 測定誤差@30A: ±0.2A
- 測定誤差@10A: ±2.0%
- 測定誤差@05A: ±4.0%

ADC基準電圧は、精度を優先し1.1Vを使用する。
必要利得は

20.95 = 1100 / 52.5

利得は`ROUT/RIN`で設定する。
RINの範囲にはLT6106内部電流の制約がある。

> 内部電流の上限は1mA、30A時のセンス電圧52.5mVを流すには
> RIN ≥ 52.5mV / 1mA = 52.5Ω
> が必要。
> データシート条件から
> RIN ≤ 500Ω

よって

52.5Ω < RIN < 500Ω

- RIN=240Ω
- ROUT=4.7kΩ (Av≈19.58)
- 出力@30A=1.028V
- 実効FS≈32.1A

出力フィルタは2段LPF構成にする。

- 1段目(LT6106付近): ROUT(4.7kΩ) × COUT1(0.1μF) ≈ 338Hz
    - PWMノイズ(16〜32kHz)を発生源で大幅減衰（-33dB以上）
    - フィルタ後の出力インピーダンスが高周波で低くなり、配線のアンテナ化を抑制
- 2段目(ADC付近): Rs(100Ω) × COUT2(10nF) ≈ 160kHz
    - 長配線で新規に拾ったHFスパイク（FETスイッチング過渡、RF誘導）を叩き落とす
    - ATtiny1604のSAR ADC S/Hキャパへのローカル電荷供給も兼用

```
┌───────┬───────┬──────────────────────────────────────┐
│ 素子  │  値   │                 用途                 │
├───────┼───────┼──────────────────────────────────────┤
│ RIN   │ 240Ω  │ 入力抵抗                             │
├───────┼───────┼──────────────────────────────────────┤
│ ROUT  │ 4.7kΩ │ 出力抵抗（利得設定 兼 1段目LPFのR）  │
├───────┼───────┼──────────────────────────────────────┤
│ COUT1 │ 0.1μF │ ROUT並列、1段目LPFのC（LT6106直近）  │
├───────┼───────┼──────────────────────────────────────┤
│ Rs    │ 100Ω  │ 2段目LPFの直列R（配線途中〜ADC直前） │
├───────┼───────┼──────────────────────────────────────┤
│ COUT2 │ 10nF  │ 2段目LPFのC（ADC直近）               │
└───────┴───────┴──────────────────────────────────────┘
```

## 電圧測定

測定地点

1. BATバランス端子: セル#1
2. BAT(+) - BAT(-): 2 - 1 = セル#2電圧
3. post-MOSFETノード - BAT(-): ESC両系統への給電電圧 (Pch-MOSFET ON確認 + 電圧降下モニタ兼用)

抵抗分圧について、精度優先で内蔵基準電圧1.1Vを使用する
MAX8.4として

- (R1+R2)/R2 = 8.4 / 1.1 = 7.64
- R1/R2 = 6.64

R1 = 67kΩ (47kΩ + 20kΩ)
R2 = 10kΩ (8.4V時 1.091V、6.0V時 0.779V)

MAX4.2の場合は R1=47kΩ にすれば良い(4.2V時 0.737V)

LT6106の電流測定と同じく、2段LPF構成で配置する

```
Vin ── R1 ──┬──[配線]── Rs ──┬── ATtiny ADC
            │                │
            R2               C2(10nF)
            │                │
            ├── C1(0.1μF)    GND
            │
           GND
```

- R1, R2, C1 は信号源側に密集させる
  - R2 をMCU側に離すと配線区間が R1=67kΩ の高インピーダンスになり、ノイズを盛大に拾う
  - R1||R2 = 8.7kΩ を信号源側で確立し、低インピーダンス信号を配線に乗せる
- Rs（100Ω）は配線途中〜ADC直前（LT6106と同規格）
  - 2段目LPFの直列R、ADC入力保護
- C2=10nF はADC直近（LT6106のCOUT2と共用規格）
  - 配線で拾ったHFノイズをADC直前でシャント
  - ATtiny1604 SAR ADC のS/Hキャパ充電にも寄与

```
┌───────┬──────────┬──────────────────────────────────────┐
│ 素子  │   値     │               用途                   │
├───────┼──────────┼──────────────────────────────────────┤
│ R1    │ 67kΩ等   │ 分圧上段（信号源側）                 │
├───────┼──────────┼──────────────────────────────────────┤
│ R2    │ 10kΩ     │ 分圧下段（信号源側、R1とセット）     │
├───────┼──────────┼──────────────────────────────────────┤
│ C1    │ 0.1μF    │ R2並列、1段目LPF（信号源側）         │
├───────┼──────────┼──────────────────────────────────────┤
│ Rs    │ 100Ω     │ 2段目LPFの直列R（電流系と共用規格）  │
├───────┼──────────┼──────────────────────────────────────┤
│ C2    │ 10nF     │ 2段目LPF（ADC直近、電流系と共用規格）│
└───────┴──────────┴──────────────────────────────────────┘
```

## 基板温度測定

Pch-MOSFET および シャント抵抗の発熱監視用に NTCサーミスタを1点実装する。

- サーミスタ: NTC 47kΩ ±5% B=4050K ±3% (TDK NTH5G20P40B473J、2012)
- プルアップ: 47kΩ ±5% (NTC R25と対称にして25°C付近の感度最大化、±5%は調達制約・表示用途なら実用上問題なし)
- フィルタ: 2段LPF構成
- ADC参照: VDD(5V) ※この1chのみ、他chは1.1V内部参照のまま

```
VCC(5V) ── R_pu 47kΩ ──┬──[配線]── Rs ──┬── ATtiny ADC (PA7)
                       │                │
                       NTC 47kΩ         C2 (10nF)
                       │                │
                       ├── C1 (0.1μF)   GND
                       │
                       GND
```

温度 vs ADCコード (VDD=5V, 10bit, B=4050K):

```
┌──────┬─────────┬────────┬─────────┐
│ 温度 │ NTC抵抗 │  電圧  │ ADCコード │
├──────┼─────────┼────────┼─────────┤
│ 0°C  │ 163kΩ   │ 3.88V  │  795    │
│ 25°C │ 47kΩ    │ 2.50V  │  512    │
│ 60°C │ 11.3kΩ  │ 0.97V  │  198    │
│ 85°C │ 4.84kΩ  │ 0.47V  │   96    │
│100°C │ 3.06kΩ  │ 0.31V  │   63    │
└──────┴─────────┴────────┴─────────┘
```

Pch-MOSFET裏面の銅箔ベタに密着させ、シャント抵抗発熱も熱結合で捕捉する。
シャットダウン閾値はマージンを取り ADCコード 110 (公称 82°C) 付近で発動、
最悪ケース (B+3%, R25+5%) でも実温度 85°C を超える前に遮断される想定とする。

## ATtiny1604

ATtiny1604の消費電力は小さいので、BAT接続時は常に稼働させる

```
BAT(+) ---+---------- (VIN) AP7375 (VOUT) -+--- (A)▷|(K) --- VCC rail --- ATtiny1604
          |                  |             |         D2                   UPDI 5V pin
          | CIN=1μF          |             |
          |                  |             | COUT=10μF
BAT(-) ---+------------------+-------------+
```

- LDO: AP7375(5V300mA)
- 内蔵オシレータ使用
- UPDI引き出し
- 逆流防止ショットキー D2

BAT未接続状態でもArduino Uno経由でUPDI書き込みできるよう、AP7375出力とVCC rail間にショットキーダイオードを挿入する。

- 型番: RB160M-30TR (ROHM, 30V 1A)
- パッケージ: SOD-123F (PMDS、フラットリード)
- VF: 0.43V @ 1A、実動作の~10mA負荷では ~0.2V
- VCC rail電圧: 5.0V - 0.2V ≈ 4.8V（ATtiny動作範囲1.8-5.5V内）

```
AP7375 --+-- (A)▷|(K) ----+----- ATtiny VCC (pin 1)
         |      D2         |
         |                 +--- UPDI header 5V pin
         C2=10μF           |
         |                 C_bypass=0.1μF
        GND               GND
```

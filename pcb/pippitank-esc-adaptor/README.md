# ESCアダプタ基板

AM32 ESC(ARTERY AT32F421ベース、25A級) をシャーシに実装するためのアダプタ基板。
ESC × 2枚分で運用する。

## 目的

ESC本体を単独でシャーシに固定・配線するのが困難であるため、アダプタ基板に実装して機械・電気の一体化を図る。

## 全体構造

アダプタ基板の半月形状にし、内側2面でキャスタレーションする。
ESCを載せて実装。
各種コネクタ、バルクCの実装が容易になる想定。

追加パーツ:
定常5~15A、ピーク20~25A想定
ケーブルは18AWG

- コネクタ(電源): XT30PW-M
- コネクタ(出力): MR30PW-M
- コネクタ(信号): JST_XH_2PIN

銅箔はコスト、実用性の両面から、1oz。
両面にベタでstitching via。

電流容量検証(1oz 両面, 5mm幅相当):
- 連続容量 ≈ 14-16A(単層 8A の約2倍、2oz単層以上)
- 常用 5-15A、stall 瞬時 25A の要件に適合
- 発熱 0.16W@15A、温度上昇 10°C 未満

### バルクコンデンサ

ESCのBAT+/BAT-近傍に配置。
330μF、ESR性能重視。

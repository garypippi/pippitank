# pippitank-esc-adaptor rev_b

rev_a (2026-05-13 発注、2026-05-18 着) の実物検証で判明した課題を反映する次リビジョン。

**状態: 凍結 (2026-07-10)。rev_a が床走行まで実用に足りたため、着手トリガーは rev_a の故障・破損。**
本 README は着手時の申し送り集約として維持する。

## rev_a からの申し送り

### 1. Castellation スロット径拡大

rev_a は drill 0.6mm (JLCPCB 最小値) で設計、実物観察で側面銅露出が不足することが判明。

| Pad | 用途 | rev_a Size / Drill | rev_b 案 Size / Drill |
|---|---|---|---|
| 1, 2 | BAT+/BAT- | 3.0×2.5 / **0.6** | 3.0×2.5 / **1.0** |
| 3, 4, 5 | U/V/W 相出力 | 2.5×3.0 / **0.6** | 2.5×3.0 / **1.0** |
| 6, 7 | S/GND 信号 | 2.0×1.5 / **0.6** | 2.0×1.5 / **0.8** |

注: 寸法は JLCPCB castellation 仕様 (最小ピッチ・最小スロット径・推奨アスペクト比) を発注前に再確認すること。

### 2. QC 指標の変更

rev_a で「側面フィレット」を QC 指標としていたが、castellation の側面銅露出が
スロット内壁の半周のみであることが実物で確認された。形成不能なケースが標準となるため、
QC 指標として trivially に汚染される。

→ **rev_b 以降は「上面パッドのフィレット角度」を一次QC指標とする**。
   側面フィレットは形成されれば加点、未形成でも不合格にはしない。

### 3. U/V/W キャスタレーションのエッジカット中心ズレ

rev_a Known Issue より、U/V/W のエッジカットがスルーホール中心を通っていない。
rev_b で修正必須。

## 電流要件 (2026-06-26/27 床走行実測で確定)

rev_a 時代の仕様要求「常用 5-15A / ピーク 25A」は実測前の想定値だった。
床走行 Baseline (2S LiFe, 60:1 ウォーム, 超信地旋回・きびきび ramp 込み) の実測:

| 項目 | 実測値 |
|---|---|
| ESC 1台あたり DC 入力ピーク | **~3.5A** (きびきび ramp / 超信地旋回時) |
| 合計ピーク (2 ESC) | ~7A |
| 定常直進 | 1〜1.5A / ESC |
| 電圧サグ | 0.35V (系抵抗 ~78mΩ と整合、熱・電圧とも問題なし) |

**rev_b の設計電流は「各 ESC 10A」を採用** (engine rev_b 電流バジェット: 全体 30A = ESC 10A×2 + システム 10A と整合)。実測ピーク比で ~3倍のマージン。

### 注意 1: U/V/W 相電流は DC 入力より大きい

シャント実測は ESC の DC 入力側。相出力 (U/V/W) には duty < 100% で
DC 側より大きいトルク電流が流れる (一次近似 I_phase ≈ I_dc / duty)。
実測ピーク時 duty ~50% なら相側 ~7A 相当 → U/V/W パッドも 10A 基準で設計しておけば吸収できる。

### 注意 2: 個別ブランチの最悪ケース = 信地旋回は未測定

超信地旋回 (両履帯逆回転) はメイン電源パスの最悪ケースだが、片 ESC に旋回仕事が
集中する**信地旋回 (`l=±X, r=0`) は未取得**。片肺ピークが超信地の 1.5-1.6A/側を上回る
可能性はあるが、10A 設計に対して桁の余裕があるため設計ブロッカーではない。
詰める場合は信地旋回ログを別取りする。

## rev_a 許容電流試算 (参考、1oz Cu, IPC-2152 外層基準)

ボトルネックは上面パッド幅。バレル(半円メッキ)寄与は 2-3 割。

| 部位 | 連続容量 ΔT=10°C | 連続容量 ΔT=20°C |
|---|---|---|
| BAT± (3.0mm pad) | 11-12A | 15-17A |
| U/V/W (2.5mm pad) | 9-10A | 13-14A |

設計電流 10A に対し **rev_a 寸法のままでも ΔT=10°C 圏でほぼ収まる**。
したがって rev_b の drill 拡大 (0.6→1.0mm) の主目的は電流容量ではなく
**側面銅露出の改善 (はんだ濡れ性・QC 判定可能性) とマージン上積み**に整理される。
パッド拡大は必須ではなくなった (スペースと JLCPCB 制約次第の任意項目)。

# Pippitank

ラズパイ戦車制作プロジェクト

- 電源: 2S Li-Po
- Raspberry Piでカメラ連携、リモート操作
- プッシュ型ソレノイドでBB弾発射

     |       |                       |  |       |

| ESC#1 |  | ESC#2 |-----------------+  |       |
